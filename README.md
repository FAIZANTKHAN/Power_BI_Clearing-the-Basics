# Basic Power BI Analytics Dashboard

## 📌 Project Overview
This is a foundational Power BI project created to practice and demonstrate my core data analytics and business intelligence skills. The focus of this project was hands-on learning, data manipulation, and mastering dashboard interactivity.

## 🎯 Learning Objectives & Features
* **Data Exploration:** Cleaning and preparing a basic dataset for analysis.
* **Interactive Design:** Implementing dynamic pivot filters, slicers, and timelines.
* **Dashboard Layout:** Designing intuitive, user-friendly visual layouts.
* **Skill Building:** Transitioning theoretical analytics concepts into practical application.

## 🛠️ Tools Used
* **Power BI Desktop:** For data modeling and visualization.
* **Excel / CSV:** As the primary data source.
